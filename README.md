# 2. Conditional Statements

After learning the basics, I am learning how programs make decisions.

Topics include:

* `if`
* `elif`
* `else`
* Nested conditions
* Multiple conditions
* Logical operators

Example:

```python
marks = 75

if marks >= 80:
    print("Excellent")
elif marks >= 60:
    print("Good")
else:
    print("Keep practicing")
```

These concepts are important because they allow programs to behave differently depending on the situation.

---

# 3. Loops 🔁

Loops are an important part of programming because they allow us to repeat tasks efficiently.

I am learning:

### `while` loops

```python
i = 1

while i <= 5:
    print(i)
    i = i + 1
```

### `for` loops

```python
for i in range(1, 6):
    print(i)
```

I am also learning:

* `break`
* `continue`
* `pass`
* Nested loops
* Loop conditions
* `for` loops with `else`
* `while` loops with `else`

I am practicing increasingly complex examples so that I can understand **how loops actually work**, rather than simply memorizing their syntax.

# 8. Exception Handling

Programs don't always run perfectly.

I will learn how to handle errors using:

* `try`
* `except`
* `else`
* `finally`
* Raising exceptions

Example:

```python
try:
    number = int(input("Enter a number: "))
    print(number)
except ValueError:
    print("Please enter a valid number.")
```
